How to get your free Google API key
1
Go to console.cloud.google.com and sign in with your Google account
2
Create or select a project, then go to APIs & Services → Library
3
Search for "Places API (New)" and click Enable
4
Go to Billing in the sidebar and link a card. Google gives $200 free credit/month - more than enough for thousands of scans. You won't be charged unless you massively exceed this.
5
Go to APIs & Services → Credentials → Create Credentials → API Key, copy the key
6
Paste your key below and click Save
⚠️ If you restrict your API key by API, make sure "Places API (New)" is ticked - not the old "Places API".
